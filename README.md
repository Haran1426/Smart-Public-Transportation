# 언제와

자주 타는 서울 버스와 지하철의 도착 정보를 Android 홈 화면에서 확인하는 앱입니다.

## 사용 방법

1. [GitHub Releases](https://github.com/Haran1426/Smart-Public-Transportation/releases)에서 APK를 받아 Android 기기에 설치합니다.
2. 처음 실행하면 녹사평역 6호선 응암 방면과 용산03 삼각지역 정류장(03567)이 기본 구간으로 표시됩니다. 다른 구간은 **구간 추가**에서 등록합니다. 버스 번호를 입력하거나 **정류장으로 찾기**에서 정류장 이름 또는 번호로 검색할 수 있습니다. 다음 정류장을 확인해 타는 방향을 고른 뒤 저장합니다.
3. 도착 목록에서 구간을 누르면 탑승 안내가 바뀝니다. 버스는 **전체 노선**에서 정류장 순서를 볼 수 있고, **지도에서 보기**로 해당 정류장을 찾을 수 있습니다.
4. 카드에서 **위젯 추가**를 눌러 표시할 정류장이나 역, 밝은·어두운 테마, 도착 시간 형식과 표시 항목을 선택합니다. 미리보기에서 확인한 뒤 **홈 화면에 추가**를 누릅니다.
5. 홈 화면의 위젯 목록에서 **언제와**를 추가할 수도 있습니다. 배치한 위젯은 Android 12 이상의 지원 런처에서 길게 눌러 다시 설정할 수 있습니다. 앱 테마는 도착판 상단의 해·달 버튼으로 바꿉니다.
6. 위젯의 새로고침 버튼이 켜져 있으면 앱을 열지 않고 다시 조회할 수 있습니다. 위젯의 남은 시간은 마지막 조회 시점 기준입니다. 자동 갱신은 Android가 관리합니다.

## 도착 정보

앱과 홈 위젯은 같은 도착정보 서버에 연결합니다. 사용자에게 인증키 입력을 요청하지 않습니다. 서버 URL을 넣지 않은 빌드에서는 기본 두 구간에 **예시 데이터**가 표시됩니다.

공식 인증키는 운영 서버 환경 변수에만 설정합니다.

- `SEOUL_SUBWAY_KEY`는 [서울 열린데이터광장 지하철 실시간 도착정보](https://data.seoul.go.kr/dataList/OA-12764/F/1/datasetView.do) 인증키입니다.
- `SEOUL_BUS_KEY`는 [공공데이터포털 서울특별시 버스도착정보조회 서비스](https://www.data.go.kr/data/15000314/openapi.do)에서 이용 승인을 받은 디코딩 키입니다.

`server/transit_api.py`의 WSGI 앱 `app`을 HTTPS로 제공하는 서버에 배포합니다. 서버는 키를 이용해 공식 제공처를 조회하고 앱에는 도착 데이터만 반환합니다. 모바일 앱을 빌드할 때 호스트 주소를 `TRANSIT_API_URL` 환경 변수로 전달합니다. 배포하는 서버에서 요청량 제한과 제공처 호출 한도를 설정하세요.

개발용 서버는 `python server/transit_api.py`로 실행합니다. Android 에뮬레이터용 디버그 빌드에 한해 `TRANSIT_DEBUG_API_URL=http://10.0.2.2:8765`를 사용할 수 있습니다. 서버 테스트는 `python -m unittest discover -s server`로 실행합니다.

버스 검색과 노선도에는 서울시의 2026년 9월 2일 자료를 사용합니다. [서울시 버스 노선 정보 조회](https://data.seoul.go.kr/dataList/OA-1095/L/1/datasetView.do)

## 개발

Flutter 3.50.0과 Android SDK로 빌드할 수 있습니다. Android 빌드에는 저장소의 Gradle 9.5.0 래퍼를 사용합니다. Windows에서는 Android 빌드 시 프로젝트 경로에 영문과 숫자를 사용해 주세요.

```sh
flutter pub get
flutter analyze
flutter test
flutter build apk --release
```

초기 APK는 설치 테스트를 위해 디버그 키로 서명한 미리보기입니다.
